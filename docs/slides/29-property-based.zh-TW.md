# 性質導向測試（Property-Based Testing）
### 陳述一條性質；讓機器去獵捕反例

軟體測試視覺化系列 #29
搭配工具：`/section-pbt`（[PropertyBasedTestingExplorer](../../src/components/PropertyBasedTestingExplorer.js)）

<!-- 從「以範例為本」轉到「以性質為本」的思維。學生已懂 MR（#25）；PBT 是它可操作、隨機化的近親。 -->

---

## 為什麼有這一講

- 一個以範例為本的測試，檢查的是作者想到的**一個輸入**。
- 它只能找到作者*想像過*的案例中的 bug —— 你忘掉的那個角落仍未被測。
- 性質導向測試把它翻過來：陳述一條**通則性質**，再讓生成器朝它丟**數百個輸入**。
- 機器會找到你忘掉的那個角落。

---

## 以範例為本 vs 以性質為本

```
以範例為本：   assert reverse([1,2,3]) == [3,2,1]
              ↑ 一個輸入、一個預期輸出

以性質為本：   對所有列表 xs：
                  reverse(reverse(xs)) == xs
              ↑ 一條性質、數百個生成的輸入
```

你不再*列舉答案*，而開始*陳述真理*。

---

## 三個成分

| 成分 | 角色 |
| --- | --- |
| **生成器（Generator）** | 產生形狀正確的隨機輸入（列表、整數、字串…） |
| **性質（Property）** | 一個對*每個*生成輸入都必須成立的布林值 |
| **執行器（Runner）** | 在 N 個輸入上跑該性質（如 100 個）；回報第一個失敗 |

若 N 個全通過，性質*存活*。若有一個失敗，你就拿到一個**反例**。

---

## 什麼是好的性質

性質常常和蛻變關係（#25）是同樣的形狀：

- **來回：** `decode(encode(x)) == x`
- **不變量：** `sort(xs)` 是有序的，且是 `xs` 的一個排列
- **冪等：** `sort(sort(xs)) == sort(xs)`
- **預言比對：** 快速的實作與一個慢、但顯然正確的實作結果一致
- **代數律：** `abs(x) >= 0`；`length(xs ++ ys) == length(xs) + length(ys)`

一條性質是一個不取決於你*挑了哪個*輸入的真理。

---

## 收斂（Shrinking）：從一團亂到最小失敗

當生成器找到一個失敗的輸入，它通常**又大又雜**：

```
失敗於：  [17, -4, 88, 0, 3, -4, 51, 9]
```

執行器接著**收斂**它 —— 在失敗仍持續的前提下，反覆簡化：

```
[17,-4,88,0,3,-4,51,9] → [-4,3,-4] → [-4,-4] → [a, a]
```

收斂交給你**最小的**、仍會失敗的輸入 —— bug 往往因此變得顯而易見。這是性質導向測試的殺手級特色。

---

## 例題：一個有 bug 的 `max`

性質：`對所有 a, b：max(a,b) >= a 且 max(a,b) >= b`。

- 生成器餵進 100 個隨機 `(a, b)` 對。
- 一個對負數處理錯誤的 `max` 會失敗 —— 比方說在 `(-5, -2)`。
- 收斂把它縮到一個最小對，如 `(-1, 0)` 或 `(0, -1)`。
- 你學到的不只是它*會*失敗，還有觸發它的*最簡單*案例。

---

## 優點與限制

**優點**
- 探索的輸入空間遠大於手寫的範例。
- **收斂**把一個隨機失敗變成一個最小、可除錯的失敗。
- 性質同時兼任精確、可執行的規格。

**限制**
- 你必須能*陳述*一條性質 —— 需要和找 MR 同樣的洞察。
- 弱的性質會空洞地通過；隨機性可能漏掉罕見案例。
- 對已知的關鍵案例，搭配以範例為本的測試。

## 工具演示

在 `/section-pbt` 開啟**性質導向測試探索器**：

1. 挑一個預設（`mySort`、`buggyMax`…），讀它的性質。
2. 跑套件 —— 看許多生成的輸入一次被檢查。
3. 在一個會失敗的預設上，看反例**收斂**成最小案例。
4. 把有 bug 的預設與正確的預設對照。

---

## 小結

- 性質導向測試用*一條性質＋許多生成輸入*取代*一個範例*。
- 三個部分：**生成器**、**性質**、**執行器**。
- 好的性質是來回、不變量、冪等、預言比對、代數律。
- **收斂**把隨機失敗縮到最小形式 —— 招牌特色。

**課堂練習：** 為一個合併兩個有序列表的 `merge(a, b)` 函式，陳述兩條性質。
