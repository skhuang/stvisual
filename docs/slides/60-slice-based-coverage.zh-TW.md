# 切片覆蓋
### *以實際影響輸出的陳述式衡量測試投入*

軟體測試視覺化系列 #60 · 切片式測試
搭配工具：`/section-slicing` → 覆蓋分頁（[SliceCoverageExplorer](../../src/components/SliceCoverageExplorer.js)）

## 結構覆蓋 —— 快速回顧

兩種廣泛使用的結構覆蓋準則：

- **陳述式覆蓋** —— 每個可執行陳述式至少被一個測試執行過。
- **分支覆蓋** —— 每個條件判斷的每個分支至少被一個測試走過。

這些指標是通用的（不依賴程式所計算的內容），且使用標準插樁工具即可輕鬆收集。

**它們保證的是：** 沒有任何陳述式（或分支）完全被測試套件忽略。

**它們無法保證的是：** 被執行的陳述式是否就是*與你關心的輸出相關的*陳述式。

<!-- 陳述式覆蓋與分支覆蓋自 1970 年代（Myers 1979、McCabe 1976）以來一直是業界基準。它們成本低廉、工具支援完善（Istanbul、JaCoCo、gcov），並被許多安全標準（DO-178C、ISO 26262）所要求。但它們與輸入無關：一個陳述式是否「被覆蓋」，與它是否參與產生任何被測輸出無關。 -->

---

## 限制 —— 覆蓋不等於相關性

考慮一個有兩條不同計算路徑的函式：

- 路徑 A：計算測試所檢查的輸出變數。
- 路徑 B：計算某個內部狀態，在此次執行中對該輸出沒有任何影響。

走過路徑 A 與路徑 B 的測試**完全滿足陳述式覆蓋**。
但路徑 B 的陳述式對所觀察的輸出毫無貢獻——測試它們對於輸出是否正確毫無助益。

**差距所在：** 一個陳述式被執行就算「被覆蓋」，不管它是否影響了受測輸出。

切片覆蓋透過將覆蓋分母限縮為輸出的**向後切片**中的陳述式，來彌補這個差距——只有這些陳述式*才可能*影響該輸出。

<!-- 這一點由 Weiser（1984）正式表述，後來由 Gyimóthy、Beszédes 與 Forgács（1999）在《An Efficient Relevant Slicing Method for Debugging》中進行了實證研究。其直覺是：執行一個無法影響被觀察輸出的陳述式，對該輸出的正確性不提供任何證據。 -->

---

## 向後切片作為相關陳述式集合

輸出變數 `v` 在陳述式 `s` 處的**向後切片**（記為 `S(v, s)`）：
> 所有*可能*影響 `v` 在 `s` 處之值的陳述式集合，同時考慮資料相依與控制相依。

這正是那些「正確執行」對 `v` 的正確性而言**不可或缺**的陳述式集合。

未能執行 `S(v, s)` 中某個陳述式的測試，無法暴露該陳述式對 `v` 的貢獻中的缺陷——無論它覆蓋了多少其他陳述式。

**核心洞見：** 輸出的向後切片定義了該輸出的*相關覆蓋全集*。

<!-- 資料相依：陳述式 t 定義了陳述式 s 所使用的變數。控制相依：s 的執行取決於 t 處所走的分支。這兩者共同構成程式相依圖（PDG），由 Ferrante、Ottenstein 與 Warren（1987）引入。向後切片是 PDG 中的逆向可達性閉包。 -->

---

## 切片覆蓋 —— 定義

設 `T` 為一個測試套件，`v` 為感興趣的輸出。

`v` 相對於 `T` 的**切片覆蓋**：

$$\text{SliceCov}(v, T) = \frac{|\{s \in S(v) \mid \exists t \in T : t \text{ 執行了 } s\}|}{|S(v)|}$$

- 分子：`T` 中至少有一個測試*執行過*的切片陳述式數量。
- 分母：輸出 `v` 的向後切片中的陳述式總數。

$$\text{切片覆蓋}(v, T) = \frac{\text{已覆蓋的切片陳述式數}}{\text{切片大小}}$$

**100% 切片覆蓋**意味著每個可能影響 `v` 的陳述式都被測試套件執行過——這比單純的 100% 陳述式覆蓋提供了更強的保證。

<!-- 此公式在概念上與陳述式覆蓋相同，但分母限縮為切片。這一限縮使其對以輸出為中心的測試具有實質意義。這個想法以各種形式出現在文獻中；Gyimóthy 等人（1999）提供了第一個系統性的實證研究。 -->

---

## 切片覆蓋 vs 普通陳述式覆蓋

| 屬性 | 陳述式覆蓋 | 輸出 `v` 的切片覆蓋 |
|---|---|---|
| 分母 | 所有陳述式 | `S(v)` 中的陳述式 |
| 100% 意味著 | 每個陳述式都被執行 | 每個切片陳述式都被執行 |
| 對無關程式碼敏感？ | 是——無關程式碼會虛高百分比 | 否——無關程式碼被排除在外 |
| 能偵測到輸出相關路徑的缺口？ | 只能偶然偵測到 | 設計上即能偵測 |

**關鍵觀察：** 一個陳述式可以**完全滿足陳述式覆蓋卻不在任何輸出的切片中**——測試它對任何輸出的正確性不提供任何證據。

反之，一個陳述式可以**在切片中卻從未被執行**——這是一個真實的缺口，而陳述式覆蓋可能被無關程式碼的覆蓋所掩蓋。

<!-- 範例：一個總是被執行的日誌分支會寫入檔案，覆蓋了那些陳述式。但如果被測輸出是一個數值回傳值，日誌陳述式就在該輸出的切片之外，對該輸出的切片覆蓋毫無貢獻。關鍵在於分母的差異。 -->

## 實作範例 —— `classify`

```javascript
function classify(n) {
  let label = "zero";       // s2
  let sign = 0;             // s3
  if (n > 0) {              // s4
    label = "positive";     // s5
    sign = 1;               // s6
  } else if (n < 0) {       // s7
    label = "negative";     // s8
    sign = -1;              // s9
  }
  return label;             // s11
}
```

輸出：`s11` 處的 `label`。

`label` 在 `s11` 處的**向後切片**：{s2, s4, s5, s7, s8, s11} —— 共 **6 個陳述式**。

`s3`、`s6`、`s9`（`sign`）**不在**切片中：`sign` 沒有通往 `label` 的路徑。

<!-- s3 定義了 `sign`；s6 與 s9 更新它。但 `sign` 從未被用於任何抵達 `label` 的計算。陳述式覆蓋會在任何測試執行到這些陳述式時計為「已覆蓋」；切片覆蓋正確地將其排除在分母之外。注意：s7 確實在切片中，因為它是控制節點（else if），決定 s8 是否執行，而 s8 對 s11 處的 label 有資料相依。 -->

---

## 實作範例 —— 三條測試軌跡

| 測試 | 輸入 | 執行陳述式 | 已執行的切片陳述式 |
|---|---|---|---|
| `pos` | n=5 | s2, s3, s4, s5, s6, s11 | s2, s4, s5, s11 |
| `neg` | n=−3 | s2, s3, s4, s7, s8, s9, s11 | s2, s4, s7, s8, s11 |
| `zero` | n=0 | s2, s3, s4, s7, s11 | s2, s4, s7, s11 |

切片 = {s2, s4, s5, s7, s8, s11}

三個測試全部啟用時：每個切片陳述式都被覆蓋 → **切片覆蓋 = 6/6 = 100%**。

陳述式覆蓋也是 100%——但請注意：`s3`、`s6`、`s9` 在陳述式覆蓋中顯示為「已覆蓋」，即使它們對 `label` 的切片覆蓋毫無貢獻。

<!-- 每個測試覆蓋 if-else 鏈的不同分支，因此覆蓋不同的切片陳述式子集。三個測試合在一起，完全涵蓋了 6 個切片陳述式。s3/s6/s9（sign 的賦值）被各測試執行，但從不進入切片分母——它們是「額外的」覆蓋，無法增強我們對 label 正確性的信心。 -->

---

## 移除 `neg` 測試 —— 缺口出現了

僅使用 `pos` 與 `zero` 時：

| 切片陳述式 | 已覆蓋？ |
|---|---|
| s2 | 是 |
| s4 | 是 |
| s5 | 是（由 `pos`） |
| s7 | 是（由 `zero`） |
| s8 | **否** —— 只有 `neg` 才走這個分支 |
| s11 | 是 |

**切片覆蓋 = 5/6 = 83%** —— s8 處的缺口清晰可見。

不含 `neg` 的陳述式覆蓋：`s8` 與 `s9` 未被覆蓋，`s3`、`s6` 已被覆蓋。
切片覆蓋正確地將注意力集中在 `s8` 這個與輸出相關的缺口上，而非 `s3`、`s6` 的無關執行。

<!-- 這是教學重點：陳述式覆蓋會顯示 s3 與 s6 為「額外已覆蓋」，並將 s8 與 s9 都報告為缺失。切片覆蓋只顯示 s8 為缺失（s9 不在切片中），並完全不計入 s3/s6——分母正確地排除了它們。結果是一個更清晰的信號，反映什麼對輸出正確性真正重要。 -->

## 小結

- **結構覆蓋**（陳述式／分支）衡量陳述式是否被執行，與其對任何特定輸出的相關性無關。
- 每個輸出的**向後切片**定義了其執行對該輸出正確性**必要**的陳述式集合。
- **切片覆蓋** = 已覆蓋的切片陳述式數 ÷ 切片大小——將分母限縮為與輸出相關的陳述式。
- 一個陳述式可以**滿足陳述式覆蓋卻與切片無關**（不在任何輸出的切片中）：執行它對任何輸出的正確性不提供任何證據。
- 一個陳述式可以**在切片中卻未被覆蓋**：這是一個真實的缺口，粗粒度的結構指標可能被無關程式碼所掩蓋。
- 切片覆蓋是結構覆蓋的**補充**，而非替代——兩者應共同使用。

**課堂練習：** 對 `classify` 函式，找出所有輸出，並分別計算每個輸出的向後切片與切片覆蓋。
