> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Branch:** `feat/slicing-deck-screenshots` (created; design spec already committed).

## Task 1: The capture script + the 16 PNGs

**Files:**
- Create: `scripts/capture-slicing-screenshots.mjs`
- Create (generated): `docs/assets/slides/slice-*.png`, `slice-*-en.png`

**Reference material — read before writing the script:**
- `scripts/capture-slide-screenshots.mjs` — the existing deck-#3 capture script. Copy its overall structure: `isServerUp()` / `startServer()` (spawns `python3 -m http.server 4173`), the Chromium launch with `viewport: { width: 1440, height: 900 }, deviceScaleFactor: 2`, the `SLIDE_LOCALE` env var (`'en'` → `-en` suffix, else bare name) and its `shot(name)` helper, the `addInitScript` that sets `window.localStorage.setItem('stvisual.locale', SLIDE_LOCALE)`, and the server-cleanup at the end.
- `src/tests/ProgramSlicingExplorer.test.jsx`, `src/tests/SliceDicingExplorer.test.jsx`, `src/tests/SliceCoverageExplorer.test.jsx`, `src/tests/SliceRegressionExplorer.test.jsx` — these show, in jsdom, the exact click sequence to drive each explorer into a given state. Mirror those sequences with Playwright `getByTestId(...).click()`.
- The four explorer components (`src/components/Slice*Explorer.js`, `ProgramSlicingExplorer.js`) — for any testid not obvious from the tests.

**Navigation:** the URL router resolves `?explorer=<Component>` to the right section + tab. Open `http://127.0.0.1:4173/index.html?explorer=<Component>&lang=<locale>` and wait for the explorer root testid. Components and root testids:

| Deck | `?explorer=` value | root testid |
| --- | --- | --- |
| #58 | `ProgramSlicingExplorer` | `program-slicing-explorer` |
| #59 | `SliceDicingExplorer` | `slice-dicing-explorer` |
| #60 | `SliceCoverageExplorer` | `slice-coverage-explorer` |
| #61 | `SliceRegressionExplorer` | `slice-regression-explorer` |

(If `&lang=` is not honoured, the `addInitScript` localStorage `stvisual.locale` set before navigation governs the UI language — that is the mechanism the existing script relies on.)

**The 8 screenshots** — for each, drive the explorer to the target state, `await sleep(250)` for the render to settle, then screenshot the explorer element (`page.getByTestId('<root testid>').screenshot({ path: shot('<base name>') })`):

| Base name | Explorer | Target state — interactions |
| --- | --- | --- |
| `slice-program-backward` | `ProgramSlicingExplorer` | First example (`gradeAverage`, loaded by default). Set the criterion: click the output statement in the code listing (`[data-stmt="s10"]`, `return grade`), then click its variable chip `[data-testid="slicing-var-grade"]`. Ensure direction is **Backward** (`[data-testid="slicing-dir-backward"]`) and mode is **Static** (`[data-testid="slicing-mode-static"]`). |
| `slice-program-dynamic` | `ProgramSlicingExplorer` | From the previous state, click `[data-testid="slicing-mode-dynamic"]`, then click a trace chip `[data-testid="slicing-trace-pass"]`. |
| `slice-dicing-static` | `SliceDicingExplorer` | Click `[data-testid="dicing-mode-static"]`, then the `summaryStats` scenario chip `[data-testid="dicing-scenario-summary-stats"]` (confirm the exact scenario id by reading `src/data/dicingScenarios.js` — use whatever id the static `summaryStats` scenario actually has). |
| `slice-dicing-dynamic` | `SliceDicingExplorer` | Click `[data-testid="dicing-mode-dynamic"]`, then the `fare` scenario chip `[data-testid="dicing-scenario-fare"]` (confirm the exact id in `src/data/dicingScenarios.js`). |
| `slice-coverage-full` | `SliceCoverageExplorer` | Click the `classify` example chip `[data-testid="coverage-example-classify"]`. Selecting an example resets the suite to all traces on — this is the 100% state; no further clicks. |
| `slice-coverage-gap` | `SliceCoverageExplorer` | From the `classify` example with all traces on, click the `neg` trace chip `[data-testid="coverage-trace-neg"]` to drop it — the coverage falls to 83% with the `s8` gap. |
| `slice-regression-static` | `SliceRegressionExplorer` | Click `[data-testid="regression-example-classify"]`; click statement `[data-stmt="s3"]` to mark the edit; click `[data-testid="regression-mode-static"]`. |
| `slice-regression-dynamic` | `SliceRegressionExplorer` | From the previous state (`classify`, `s3` edited), click `[data-testid="regression-mode-dynamic"]`. |

The script must `console.log` each saved file. End by killing the spawned server (if it started one) and `browser.close()`.
